## 2. 忖度なしの指摘：そのまま真似ると弱い点

1. **ノウハウ止まり**
   「機能より未来を見せよう」は、すでに学んでいる層は知っている。
   美智代さんのターゲットは「知ってるのにできない人」。
   → 記事の核は **「なぜ分かっていても説明してしまうのか」** に置く。ここが差別化。

2. **「口コミ＝SNSに載せる声」で止まっている**
   参考投稿の口コミは「ストーリーに載せるお客様の声」。
   美智代さんの講座は「口コミが自然に生まれる仕組み」。レイヤーが一段深い。
   → 「声を載せる」の先に **「紹介が起きる仕組み」** があることを匂わせて終える（講座への橋）。

3. **バンドワゴン効果は誰でも書ける**
   → 脳科学の視点を1つ足すだけで、一気に「美智代さんの記事」になる。

## 3. 記事の切り口案（タイトル候補）

- 「資格もある。説明もしている。それでも申し込みが来ない理由」
- 「丁寧に説明するほど、あなたのセッションは選ばれなくなる」
- 「『いいのはわかるけど、今じゃなくていい』と言われるセラピストの共通点」
- 「お客様の声、たった1件でいい。でもあなたはその1件を頼めていない」
- 「元教員の私が気づいた。説明が上手い人ほど集客で苦しむ理由」

※5本目は美智代さんの経歴（教員20年以上）が生きる。おすすめ。
　「教える力が高い人ほど説明に寄る」は、読者の多くに当てはまる代弁になる。

---

## 4. 構成案（セラピスト・講師版）

1. **代弁から入る**
   「このセッションでは〇〇が整います」「初めての方でも安心です」
   ちゃんと書いている。なのに反応がない。
   読まれてはいる。いいねもつく。でも、申し込みだけが来ない。

2. **原因を言い当てる**：説明しすぎている
   お客様の頭の中は「へぇ、いいね。…でも、今じゃなくていいかな」。

3. **原理（脳の話）**：人は「機能」ではなく「変わった自分の姿」で決める
   - セラピー例：「60分の対話セッション／潜在意識にアプローチ」
     → 機能。読み手は「ふーん」。
   - 変換後：「夫に言い返せなかった私が、初めて自分の気持ちを言えた夜」
     → 読み手の頭に"場面"が浮かぶ。ここで初めて「私も」が起きる。

4. **具体例（お客様の声の書き換え）**
   - Before：「とても良かったです。またお願いします」
   - After：「朝、鏡を見て『今日の私、悪くない』と思えた。そんなの何年ぶりだろう」
   → 声は「感想」ではなく「変化の場面」で載せる。

5. **ここが本題：なぜ分かっていても説明してしまうのか**
   - 「ちゃんと説明しないと、信用されない気がする」
   - 「お客様の声をお願いするのは、図々しい気がする」
   - 「成果を語るのは、盛っているようで怖い」
   → これは**ノウハウ不足ではなく、思い込み（思考のクセ）の問題**。
   → 美智代さんの領域：脳科学・NLP・セルフクリアリングにつなげる。

6. **小さな一歩**：口コミは1件でいい
   今週、1人だけに「何が変わった？」と聞いてみる。
   感想ではなく「変化」を聞く質問にする。

7. **まとめ**（保存されやすい箇条書き）
   1. 説明だけで終わらせない
   2. 「変わった後の場面」を見せる
   3. 声は1件でいいから出す
   4. 出せない自分の思い込みに気づく ← ここが美智代さんオリジナル

8. **CTA（導線）**
   「声を載せる」のは入口。本当に大事なのは、紹介が自然に生まれる仕組み。
   → メルマガ登録／体験講座へ。

## 5. 脳科学で差別化するネタ（確信度つき）

| ネタ | 使い方 | 確信度 |
|---|---|---|
| 社会的証明（チャルディーニ『影響力の武器』） | 「みんな受けてるなら安心」はバンドワゴンと同系統。名前を変えて紹介できる | 高 |
| 人は未来の自分を具体的に想像できると行動しやすい（エピソード的未来思考） | 「変化の場面」を見せる理由づけ | 中（研究はあるが、集客への直結は解釈を含む） |
| 損失回避（得るより失う痛みを強く感じる） | 「今のままでいると…」の書き方の根拠 | 高 |
| ミラーニューロンで共感が起きる | **使わない方が安全**。学術的に議論が分かれ、断定すると突っ込まれる | 低 |

※講座で使っている脳科学理論（認定インストラクター資格の内容）がある場合は、そちらを優先。
　一般論より「私が認定を受けて教えている理論では」と言えるほうが強い。
　※理論の固有名（脳大成理論）は使わない。「脳科学」「認定を受けて教えている理論」と表現する。

## 7. 書く時の注意（トーン）

- 「初心者でも簡単」系の表現はNG方針に合わない。読者は「もう学んでいる人」として書く。
- やさしく終わらせない。「説明を足しても、今のままでは変わらない」と一度はっきり言う。
- 参考投稿の「パン教室」例は使わない。セラピー・コーチ・講座の場面に完全に置き換える。
- 参考投稿の文言・構成の写しすぎに注意。骨格は借りても、核（第4章5）は美智代さんオリジナルで。

# talk-reel スキルの登録手順（個人用・ことはちゃん版）

画面の名前はお使いの環境で少し違うことがあります（確信度：中）。迷ったら、見えている文字を教えてください。

## 1. zipファイルを手に入れる
- `personal-skills/talk-reel.zip` をダウンロードする（GitHub のリポジトリ、またはチャットに送ったファイルから）
- **zipは開かない**（解凍しない）

## 2. Claudeの設定を開く
- Claude（claude.ai のアプリかブラウザ）を開く
- 自分の名前（アイコン）を押す → 「設定（Settings）」

## 3. スキルの場所を探す
- 「機能（Capabilities）」→「スキル（Skills）」

## 4. zipをアップロードする
- 「アップロード（Upload skill）」のボタン → talk-reel.zip を選ぶ

## 5. 確かめる
- 一覧に「talk-reel」が出て、スイッチがオンになっている
- 新しいチャットで「トークリールの台本を作りたいです。テーマは〇〇」と打つ
- テーマ・型・CTAの確認や、7ブロックの台本が返ってくれば成功

## つまずいたら
- アップロードの欄がない／「使えない」と出る → 画面に出ている文字を、そのまま Claude に伝える

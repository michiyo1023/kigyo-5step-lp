## 1. 資料の要点
| 箇所 | 要点 |
|---|---|
| 悪口はストレス発散にならない | 言葉は「自分」と「他人」を区別せず受け取る。人を非難するのは自分を責めるのと同じ、という説明。批判する人は病気のリスクや死亡率が高い、と書かれている |
| 1人で唱えても他人に向けても同じ | ほかの人をほめると、自分をほめるのと同じことになる。人のよい点を見つけてほめる人は、自分にもよい言葉を送っている |
| Work⑥ キャンセル | 疲れているとつい出る悪口やグチもある。出たら「キャンセル」。いままでの「+」は、1ポイント引かれるだけ。また新しい言葉を積み重ねればよい。自分を責める必要はない |
| 唱えるのがつらいとき（ホ・オポノポノ） | 愛する人との別れや死別、虐待などの経験がある人は、よい言葉を唱えると苦しくなることがある。そのときは無理に続けず、「ありがとう・ごめんなさい・許してください・愛してます」の4つから始める。順番は入れ替えても、飛ばしてもよい |
| 許可形（自己嫌いの克服） | 無理に自分を好きになろうとしない。「自信がなくてもよい」と許可する。「そのままで価値がある」「私は私でよい」など（第3章の締めと同じ内容） |
| 心の鎖がはずれる | 「〜すべき」「〜しなければならない」という自分のルール（マイルール）で、自分を縛ってしまう人は少なくない。もっと幸せになれるのに、1歩手前で自分を閉じ込めてしまう |
| がんばりすぎてつらいとき | 「目標を決めて一生懸命がんばる→叶ったら喜ぶ」の時代から、「先に喜ぶ・楽しむ」の時代へ、という考え方。「そのままでOK」「がんばらなくても大丈夫」「がんばりすぎないでOK」。やりたいときはやる、やりたくないときはやらない、楽しく努力する、肩の力を抜いた努力ができるようになる |
| もっと幸せになってもいい | 願いが叶ってくると、「こんなにうまくいっていいのかな」「私ばっかり幸せになっていいの？」という不安や疑問が出る。そのときは許可形で、「幸せになってよい」と許す |
| 奇跡が信じられないとき | がんばっても状況が変わらない人は、心のどこかで「奇跡なんて本当に起こるのかな」と疑っている。「そうかもしれない」と気づいたら、許可形で可能性を許す |
| 行き詰まったとき | 就職活動がうまくいかない人の例。追い詰められたときに、助けを求める言葉を唱える |
| 漠然とした不安 | 2011年の震災やコロナ禍で、不安を抱える人が急増。ニュースを浴び続けて体が拒否反応を起こした例。まずは気持ちを落ち着かせる。「何があっても大丈夫」「すべてがよい方向に向かう」などを唱える |
| 言霊は身近な人にも働きかける | 大切な人が病気で苦しんでいるとき、自分の言霊が届けられないか、という相談がある。身近な人にも影響する、という説明 |
| 相手に押しつけない | 言霊でまわりも幸せにするコツは、「こうなってほしい」「変わってほしい」と相手に自分の希望を押しつけないこと。相手と自分の希望が一致しているときだけ、願ってよい。子どもの望まない結果をあなたが望むと、エゴになりかねない |

## 3. 使わない・変える判断
1. **「批判する人は死亡率が高い」を、強く言わない。** 「敵意が強い人ほど病気のリスクが高いという研究があります。原因とは限りません」にとどめる。
2. **次の体験談は使わない。** 年商2000万円になった話、就職、受験の合格、店の売上、病気が治る・うつが回復した話、大切な人の病気に言霊を届ける話、震災・コロナの話。効果の約束に見えるため。
3. **60代の女性（息子さんの行方不明、「死のう」と思った話）は使わない。** 重い内容で、受講者に影響が大きい。
4. **「神様」「奇跡」「波動」「魂」は使わない。**
5. **「言霊は身近な人にも働きかける」は使わない。** 代わりに「自分の態度が変わると、まわりとの関係も変わることがある」までにする。
6. **ホ・オポノポノは「選択肢の1つ」にする。** 主役にしない。つらい経験のある人が無理をしないことを、先に伝える。
7. **「やりたくないときはやらない」は、そのままは使わない。** 「力を抜く日を決める」「やらない日も、決めてやらない」に置き換える。（やる気任せにすると、続かなくなるため）
8. **強い自責や「死にたい」気持ちが出る人への案内が必要です。** 「ひとりで抱えず、専門の相談窓口へ」と、窓口の連絡先を入れたい。**窓口は美智代さんが確認して、記入してください。**

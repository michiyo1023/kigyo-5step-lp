# 資料メモ③：第2章の締め（休む日・まとめ）と第3章（願いの言葉づくり・ホ・オポノポノ・感情の段階）

## 1. 資料の要点
| 箇所 | 要点 |
|---|---|
| 休む日の対応法 | 休むと決めてから休む。何となく言えずに1日が終わると罪悪感が残り、「私ってダメだな」と自信を失う。筋肉と同じで、休んだ翌日にまた負荷をかけると強くなる。休んだらまた再開すればよい |
| 第2章のまとめ | 「食べる」と言って食べるだけでも有言実行。約束の大小は気にしない。悪口もよい言葉も自分に返ってくる（自分と他人を区別しない）。悪口は「キャンセル」。幸運の予兆としてゾロ目・偶然の一致（シンクロ）を挙げている |
| 第3章 効果的な言葉づくり3つのコツ | 叶えたい願い・未来を楽しみにする感情が自然に湧くと、言葉がつくりやすい。いきなりハードルが高ければ、願いにフォーカスした言葉から始める |
| コツ① 単語だけを使う | 長い文章にすると「そんなの無理」と反発が起きる。「自信」「マイホーム」のように単語にして抵抗を減らす。単語を唱えると、その先のヒントが浮かぶこともある |
| コツ② 現在進行形にする | 「〜になりつつある」「〜に近づいている」。今の自分と矛盾せず、本音（ホンネ）が反発しない。「今は目指す途中」と理解する |
| コツ③ 許可形にする | 「〜になってよい」「〜してもよい」。謙遜の文化で自分にブレーキをかけがち。許可を与えるとリミットが外れ、幸せを受け入れやすくなる |
| 心のホンネが逆暗示になる | 唱えた言葉と本音が矛盾すると、心が反発する。ここに注意 |
| 「〇〇できたら、病気になってもいい」 | 願いを叶える代償を無意識に設定してしまう例。言葉に「犠牲・代償」を入れない |
| ホ・オポノポノ | 唱えづらい／効果が出ないときの助け。「ありがとう・ごめんなさい・許してください・愛しています」の4つ。順番は入れ替えても、飛ばしてもよい。つらい経験がある人は、無理に続けない |
| 感情の22段階（エイブラハム） | 感情を段階で捉える。1に近いほど喜び・感謝など、22に近いほど怒り・無力感など。自己否定感がもっともネガティブ度が高い。自分で自分をいじめることが一番イヤ |

## 2. 脳科学の言葉への翻訳（案）

| コツ① 単語だけ | 短い言葉は抵抗が少なく、繰り返しやすい。ただし「単語が脳に効く」という直接の研究根拠は未確認 | 続けやすさの工夫として使う。効果の断言はしない | 中 |
| コツ② 現在進行形 | 「今の自分」と「なりたい自分」の間をつなぐ言い方。「途中の自分を認める」ことで、矛盾が小さくなる | 「〜になりつつある」は、成長の途中を認める言葉として使える | 中 |
| コツ③ 許可形 | 自分に許可を与える＝無意識の制限（思い込み）をゆるめる。「そうなっていい」と許す | 起業女性の「受け取れない」「価格が上げられない」に直結する。美智代さんの「思い込みの整理」と相性がよい | 中〜高 |

| ゾロ目・シンクロ（偶然の一致） | 自分が注目しているものに気づきやすい（選択的注意）。偶然の一致を「意味がある」と感じやすい脳の性質（確証バイアス） | 「幸運の予兆」としては使わない。「気づく感度」の説明に使える | 中 |

## 3. 使わない・変える判断
1. **エイブラハムの22段階は使わない。** チャネラーの教えで、検証できません。「感情を数字で測る（0〜10）」ワークに置き換え。
2. **「悪口も自分に返ってくる」は、断定しない。** 科学的に確認できる形では、「自分の言葉は、自分の耳にも入り、気分に影響する」までなら言えます。（確信度：中）
3. **「病気になってもいい」の例は使わない。** 言葉が病気を呼ぶように聞こえ、受講者を不安にさせる恐れがあります。「無意識の代償設定」は、「成功したら孤独になる気がする」などのお金・仕事の例に置き換え。
4. **「息子さんの合格」「性皮膚炎が治った」などの体験談は使わない。** 効果の保証に見えるため。
5. **ホ・オポノポノは主役にしない。** 美智代さんの「セルフクリアリング」と役割が重なります。**ここは美智代さんの判断が必要です。**
6. **「魂が反発する」は、「本音が反発する」に言い換える。**

## 5. 第5回のワーク案（資料から作り直し）
「願いの言葉づくり」3ステップ（20分）
1. 叶えたいことを、1つ書く（例：安定した集客）
2. 3つの形に言い換える
   - 単語：「集客」「ご縁」
   - 現在進行形：「私は、集客できる自分に近づいている」
   - 許可形：「私は、選ばれてよい」「私は、受け取ってよい」
3. 声に出して、体と気分の変化を観察。違和感がある順に並べ、いちばん抵抗の少ない言葉を選ぶ

→ 「本音が反発しない言葉を選ぶ」が、O-リングの代わりの判定基準になります。

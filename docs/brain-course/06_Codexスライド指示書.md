# Codex用 スライド指示書（全7回・各60分）

作成：ことはちゃん ／ ナレーションは、Codexのスライドが届いてから、スライドに合わせて作ります。

## A. 全体ルール（Codexへ）
1. 16:9。1スライドに伝えることは1つ。
2. 文字は少なく、大きく。1スライドの本文は原則40文字以内。中学生にも伝わる言葉。
3. 専門用語は、日本語の説明を先に、用語を後に出す。（例：「脳は使うほど強くなる（神経可塑性）」）
4. 図は、たとえ話を絵にする。説明図より、情景が浮かぶ絵を優先。
5. 書籍のイラスト・図・文章は使わない。すべてオリジナル。
6. 禁止語：魂／波動／神様／奇跡／引き寄せ／好転反応／言霊／「突然ですが」。
7. 色・フォントは、落ち着いた配色（案：濃い紺＋やわらかい金＋生成り）。ブランドカラーがあれば差し替え。
8. 各回の最初に「医療の代わりではありません」の小さな注意書きを入れる。
9. ワークのスライドには、時間の目安（タイマー表示用の数字）を入れる。
10. 「研究」の話は、「〜という研究があります」と小さく添える。断言しない。
11. 各スライドの右下に、回-番号（例：S2-05）を小さく入れる。ナレーションの対応に使う。

## B. 共通の型
| 型 | 使いどころ | 作り方 |
|---|---|---|
| 表紙 | 各回の最初 | 回の番号、タイトル、一言 |
| 復習 | 2回目以降の最初 | 3問を1問ずつ出し、答えは次の画面 |
| 代弁 | 各回の最初の講義 | 受講者の本音を1行で |
| 図解 | 講義の中心 | たとえ話の絵 |
| ワーク | 20分の枠 | 手順を3つ以内、タイマー数字つき |
| まとめ | 最後 | 今日の3行（大きく） |
| 次回予告 | 最終 | 次の回のタイトルと宿題 |

## C. ナレーションを作るときのメモ（ことはちゃん用）
- 目安：1分あたり約300〜350文字。講義25分で約7,500〜8,500文字。
- 流れ：代弁（本音を先に言葉にする）→ たとえ話 → 脳の話 → 「だからこうする」。
- 研究の話は、「〜という研究があります」と小さく言う。断言しない。
- 各回の最初に、前回の復習を30秒で。最後に、今日の3行を同じ言葉でくり返す。
- Codexのスライドが届いたら、S番号ごとにナレーション原稿を作る。

## 0. 講座の約束（全回共通）
- **対象**：脳科学を知らない人。専門用語は初出で日本語の説明を添える。
- **1回60分**：復習5分 → 講義25分 → ワーク20分 → まとめ7分 → 次回予告3分
- **語りの温度**：やさしいだけで終わらない。「今のままでは変わらない。でも、あなたなら変われる」。読者の本音を先に代弁する。
- **講座の背骨**：「知っている」から「できている」への橋をかける。（すでに学んで動いているのに結果が出ない人に刺さる軸）
- **使う言葉**：脳科学／自分への言葉（セルフトーク）／習慣／注意の向け先。
- **使わない言葉**：魂・波動・神様・奇跡・引き寄せ・好転反応・言霊（講座内の説明語としては使わない）。
- **安全方針**：医療や診断の代わりではない。重い状況の方は想定しない。相談窓口の連絡先は入れない。効果の約束はしない。
- **マインドチューニング**：美智代さんのブランドの言葉。第4回に枠だけ確保（内容は美智代さんが記入）。

## 2. 各回の設計

### 第1回 脳は、あなたの言葉で動いている
- **ゴール**：①脳は使い方で変わると知る ②自分の現在地を知る ③続けるルール3つ（小さく・分けて・戻る）を持ち帰る
- **復習**：なし。代わりに「今日のコンディション0〜10」を数字にする。
- **講義の流れ**
  1. 学んだのに変わらない理由：「知っている」と「できている」は別
  2. 脳のしくみ（2つだけ）：考える部分／感じる部分
  3. 脳は使うほど強くなる（草むらの道のたとえ。専門語：神経可塑性）
  4. 自分への言葉（セルフトーク）は、いちばん近くで聞いている
  5. 目に入るものが変わる（赤い車のたとえ。専門語：選択的注意）
  6. 続けるルール3つ
- **ワーク**：①現在地チェック ②「ありがとう」と「疲れた」の体感観察（O-リングの代わり）
- **宿題**：寝る前に「今日できたこと」を1つ、声に出す。

### 第2回 小さな約束と、自分への許可
- **復習3問**：脳は使うほどどうなる？／続けるルール3つは？／声に出すと何が増える？
- **講義の流れ**
  1. 約束を守ると、自分を信じる力（自己効力感）が育つ
  2. 小さいほど効く。「いつ・どこで・何を」を決める（実行意図）
  3. 自分を責める脳と、自分にやさしい脳（セルフ・コンパッション）
  4. **感情の段階（22段階）の紹介**：感情を「地図」にして今の位置を知る。いちばん行動を止めるのは自己否定。
  5. 許可形の言葉：「〜してよい」「そのままでよい」
  6. 無理に自分を好きにならなくていい
- **ワーク**：①明日の約束3つ ②許可形を3つ作り、抵抗度0〜10をつける ③いまの感情は段階図のどこか
- **宿題**：約束を1つ決めて、できたら✓をつける。

### 第3回 感謝・よいことを探す脳
- **復習3問**：約束は大きく？小さく？／自分を責める脳に何が起きる？／許可形とは？
- **講義の流れ**
  1. 脳は危険を優先して探す（ないものに目が行く：ネガティビティ・バイアス）
  2. 感謝を探す練習は、「探す目」を育てる練習
  3. 感謝の習慣の研究（効果には幅がある、と正直に伝える）
  4. 20%の日でも「よいこと」を1つ見つける（見方を変える）
  5. 身近な人への感謝を思い出す（安全版・5分）
  6. 与える行動：感謝の行動を1つ渡す（研究のある親切行動）
- **ワーク**：①ありがとう10個 ②よいこと探し1つ ③感謝の想起5分
- **宿題**：今日、誰かに「ありがとう」を伝える行動を1つ。

### 第4回 失敗しても戻れる脳
- **ゴール**：①失敗しても「やめる」のではなく「戻る」を選ぶ ②言い直す技術を持つ ③休む日と戻る合図を先に決める
- **復習3問**：探す目を育てるとは？／よいこと探しは何のため？／感謝の行動の例は？
- **講義の流れ**
  1. +100と−1：1回の失敗で全部は崩れない
  2. 「どうにでもなれ」が起きる理由（どうにでもなれ効果）
  3. やめるのではなく、戻る
  4. 「いまのナシ」：言い直しの技術（リフレーミング）
  5. 疲れて出てしまう日もある。自分を責めない
  6. 休む日は、決めて休む
  7. 戻る合図：「もし抜けたら、次は〇〇」を先に決める（実行意図）
- **ワーク**：①言い換えカード ②休む日と戻る合図 ③今週の「できたこと」3つ
- **宿題**：「いまのナシ」を1回使う。

### 第5回 人間関係のストレスと、心の守り方
- **ゴール**：①悪口のあとの気分を知る ②相手を変えようとせず、自分の関わり方を選ぶ ③悪口のあと、自分の気分を見る習慣を持つ
- **復習3問**：+100と−1の意味は？／「いまのナシ」の目的は？／休む日の決め方は？
- **講義の流れ**
  1. 悪口のあと、気分はどうなるか（口から出た言葉は自分にも聞こえる。反芻）
  2. 苦手な人：相手を変えるのではなく、自分の心を静める
  3. 押しつけない：相手のことは、相手が決める
  4. 相手の幸せを願うフレーズ（慈悲の瞑想の応用）。無理に願わなくていい
  5. 感情の地図にもどる（第2回の図）
  6. マインドチューニング（約8分）：スッキリと洗い流す。クリアなものに入れ替わる。軸は、本来の自分。くもった窓のたとえ＋3分のミニ体験（下書き：10）
- **ワーク**：①相手の幸せを願うフレーズと気分の観察 ②苦手な人との関わり方を選ぶ ③ありがとうの行動のふり返り
- **宿題**：身近な人のよいところを1つ見つけて、心の中で伝える。

### 第6回 本音が反発しない願いの言葉
- **復習3問**：苦手な人を変えようとすると、どうなる？／「こうなってほしい」と押しつけないのは、なぜ？／悪口のあと、自分の気分はどうなる？
- **講義の流れ**
  1. 本音と矛盾する言葉は、反発を生む（逆暗示）
  2. コツ① 単語にする（長い文は「無理」が出る）
  3. コツ② 現在進行形にする（「〜しつつある」）
  4. コツ③ 許可形にする（「〜してよい」）
  5. 願いに無意識のブレーキがある（「叶ったら失うもの」を探す）
  6. 場面別に作る：お金・仕事／人間関係／自分への言葉（健康は医療の代わりにしないと明記）
  7. 言葉は行動とセットで使う
- **ワーク**：願いを1つ→3つの形→抵抗度→選ぶ→ブレーキ探し
- **宿題**：選んだ言葉を朝と夜に1回ずつ。

### 第7回 未来を先に祝う、続ける仕組み
- **復習3問（総復習）**：1回〜6回から1問ずつ
- **講義の流れ**
  1. 予祝は、未来の先取り体験（メンタルリハーサル）
  2. 祝うだけでは足りない：障害と一歩までセット（WOOP・実行意図）
  3. 習慣が定着する期間は人それぞれ（平均66日、18〜254日の幅という研究）
  4. 習慣マス表で見える化
  5. 7回の総まとめ
  6. 卒業：これからの3ヶ月
- **ワーク**：①1年後の最高の未来 ②障害と今日の一歩 ③習慣マス表 ④自分への手紙
- **次のステップ**：美智代さんの次の導線（要確認）

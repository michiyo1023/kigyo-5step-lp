# 脳科学講座（60分×連続講座）設計案 v0

作成：ことはちゃん ／ 状態：資料の途中段階（追加資料を受け取り次第、更新）

## 0. 前提（確認済み）
- 1回60分（ワーク込み）。回数はことはちゃんにお任せ。
- 各回の流れ：**復習 → 講義 → まとめ**
- 脳科学を知らない人にも伝わること。
- スライドはCodex、ナレーションはことはちゃんが担当。
- 「脳大成理論」の名前は使わない（言い換え：「脳科学」「認定を受けて教えている脳科学の理論」）。
- 元資料の文章はそのまま使わない。構造と発想を借りて、美智代さんの言葉で作り直す。

## 1. 元資料の構造（ことはちゃんの読み取り）
| 元資料の要素 | 中身 | 講座での役割 |
|---|---|---|
| 序章：4つの事実 | 魂がある／魂が神様と自分をつなぐ／魂が不機嫌だとつながれない／言葉で魂と対話できる | 全体の世界観・「なぜ言葉なのか」 |
| チェック表（A・B・C） | A=マイナス習慣（−1点）、B=土台の習慣（3点）、C=高い状態（7点）。合計で4段階に分類 | 診断・現在地の把握 |
| 第1章（〜30%） | 自分を大切にする、よい言葉の選び方、違和感のない言葉、1000日シート | 入口：自分への扱い方を変える |
| 第2章（30〜50%） | 起床時・寝る前、約束リスト、感謝、キャンセル（悪口） | 習慣化：小さく毎日 |
| 第3章（50〜70%） | 言葉をカスタマイズ、逆暗示に注意、お金・健康・人間関係 | 応用：自分の願いに合わせる |
| 第4章（70%〜） | 予祝、自分の名前、雨の日の受け入れ方 | 深化：人生に広げる |

特徴：「現在地を測る → 現在地ごとに次の一手が違う」という設計。ここは講座の骨格として強い。

## 2. 要注意：このままでは「脳科学」にならない点（確信度：高）
元資料は「神様とのシンクロ」「魂」「波動」という説明で成り立っている。脳科学の講座として出すなら、次の翻訳が必要。

| 元資料の言い方 | 脳科学の言い方（案） | 確信度 |
|---|---|---|
| 魂のゴキゲン | 脳と体のコンディション（ストレス反応が静かな状態） | 高 |
| 言霊で魂と対話 | 自分への言葉（セルフトーク）が、感情と行動を決める | 高 |
| 違和感のない言葉を選ぶ | 脳が受け入れられる言葉でないと、反発が起きて逆効果になる | 中〜高 |
| O-リングテスト | 科学的根拠が弱いので使わない。代わりに「体の違和感を観察するワーク」 | 高（使わない判断） |
| 感謝・ありがとう | 感謝の習慣と気分・睡眠・人間関係の研究 | 中 |
| 悪口のキャンセル | 反芻（同じ考えを繰り返す）を止める・言い直し（リフレーミング） | 高 |
| 願いを言霊に・予祝 | 目標設定、未来のイメージ、注意の向け方（RAS＝脳の「重要フィルター」） | 中 |
| 1000日シート | 習慣形成。※「◯日で定着」は個人差が大きい（平均66日、18〜254日の幅という研究あり）ので断言しない | 中 |
| 「神様・波動・ミラクル」 | 講座では使わない。または「世界観の言葉」として一言触れる程度 | — |

※ 研究の数字や名称は、スライド化の前に出典を確認します（私の記憶ベースのため）。

## 3. 全体設計案：全6回（各60分）
6回にした理由：認定講座の6回と揃うので、理論と対応させやすい。ただし、美智代さんの認定理論の中身（各回のテーマ）を教えてもらえたら、そちらに合わせて組み直します。

### 各回の共通フォーマット（60分）
| 時間 | 内容 |
|---|---|
| 0〜5分 | 前回の復習（3問クイズ or ひとこと振り返り） |
| 5〜30分 | 講義（脳のしくみ：たとえ話・図で） |
| 30〜50分 | ワーク（書く・声に出す・体で感じる） |
| 50〜57分 | まとめ（今日の3行＋持ち帰る1つ） |
| 57〜60分 | 次回予告・宿題 |

### 回ごとのテーマ（仮）
1. **脳は、あなたの言葉で動いている**
   現在地チェック（元資料のチェック表を、脳のコンディション診断に作り直す）／脳の基本（3つの役割だけ）
2. **自分への言葉を変える：扱い方が脳を変える**
   セルフトーク／自己批判がストレス反応を起こす／「違和感のない言葉」の選び方
3. **ありがとうが脳に起こすこと**
   感謝の習慣・約束リスト／朝と夜の習慣（起床時・寝る前）
4. **ネガティブを止める・言い直す**
   反芻思考／キャンセルとリフレーミング／切り替えスキル
5. **願いを言葉にする：逆効果にならないコツ**
   目標設定／逆暗示（本音と矛盾する言葉は効かない）／お金・健康・人間関係へのカスタマイズ
6. **続ける仕組みと、これからの自分**
   習慣化／未来のイメージ（予祝の脳科学版）／雨の日の受け入れ方／卒業ワーク

## 1. 資料の要点
| 箇所 | 要点 |
|---|---|
| 自己嫌いの克服（許可形） | 自分を好きになれない人が無理に好きになろうとすると、かえって自分を苦しめる。まず「自信がなくてもよい」と許可する。「いまの自分でよい」「そのままで価値がある」「私は私でよい」「これでよかった」などを繰り返す |
| 「毎日、あらゆる面でどんどんよくなっていく」 | 薬剤師・心理学者のエミール・クーエの言葉として紹介。何から手をつけるか分からないときに、とにかく繰り返す。少しずつ糸口が見つかる、という説明 |
| 好転反応の乗り越え方 | 言霊を始めると、一時的に眠気・だるさ・体調の変化、つらい記憶がよみがえる反応が出る人がいる、という説明。出たら一旦休む、落ち着く、つらい記憶に気づいて自分を認め、いたわる。始めたら親や周囲から否定される、トラブルが起きるのも「好転反応」と説明している |
| 第3章の言霊一覧 | お金・仕事／健康／人間関係／唱えるのがつらいとき／自分を変えたいとき／縛られているとき／がんばりすぎてつらいとき／もっと幸せになりたいとき、の場面別フレーズ集 |
| 第4章：予祝 | お花見＝秋の豊作を先に祝う習慣、という説明。願いが叶った状態を先に祝う。スポーツ選手がイメージトレーニングをするのと同じで、成功した場面を思い描くと、脳が現実と想像を区別しない、という説明。「1年後の最高の未来」をイメージする |
| 第4章の言霊一覧（奇跡・行き詰まり・不安・絶望） | 「奇跡が起こる」「何があっても大丈夫」「すべてがよい方向に向かう」など、状況別のフレーズ |
| Work⑦：20%のコンディションでも「今日も絶好調！」 | 状態が良くなくても「毎日、あらゆる面で絶好調です！」と唱える。本音が反発しそうなら、「ウソ」ではなく「見方を変えるワーク」と捉える。「もしかしたら、これが絶好調かも」と考え、いまある「よいこと」を探す（受容思考）。20%でも「絶好調」と言い切ると、100%でなくてもよいと思え、心がラクになる |
| Work⑧：嫌いな人の幸せを願う | 嫌いな人の悪口を言うと、自分もその人の苦手な部分と同調してしまう、という説明。「〇〇さんが今日もよい1日を送れますように」と願う。いきなり願うのが難しければ、まず自分から始める（慈悲の瞑想に似た方法） |

## 3. 使わない・変える判断（重要）
1. **「好転反応」は使わない。** 体調不良・だるさ・便秘・湿疹などを言霊の効果と説明するのは、受診の遅れにつながる恐れがあります。講座では「体調が悪いときは医療機関へ」と明記します。（確信度：高）
2. **「周囲に反対される・トラブルが起きる＝好転反応」は使わない。** 何が起きても正解にできる説明は、受講者を縛る恐れがあります。
3. **エミール・クーエの「驚異的な治癒率」は使わない。** 現代の科学で確認できていません。
4. **「予祝」は「引き寄せ」と言わない。** 「想像すると現実になる」ではなく、「未来を具体的に描くと、行動が選びやすくなる」まで。
5. **Work⑦の「絶好調」は、つらい人に無理に言わせない。** 「絶好調と言い切る」より「いまの中のよい部分を1つ見つける」に軽くする。
6. **「神様」「奇跡」「天之御中主様」「波動」は使わない。** 言霊一覧は、神様・奇跡系を除いて、「そのままでOK」「がんばらなくても大丈夫」「少しずつ心が解放される」系だけを使います。
7. **斎藤一人さんなど実在の人物の引用は使わない**（引用するなら出典確認が必要）。
8. **「53kgを維持」「黒髪になった」などの健康・美容の言霊は使わない。** 効果の約束に見えるため。

# 参考：感情の22段階（英語の紹介ページの和訳・仮）

作成：ことはちゃん ／ 状態：**仮。美智代さんの本のページと照合してから、スライドに使う**

## 出典と注意
- 出典：英語の紹介ページ（https://jodiecook.com/the-emotional-guidance-scale ）。ほかの検索結果とも大筋は一致。ただし、紹介ページによって表記や順番に違いがある。
- 原典は、エスター＆ジェリー・ヒックス『Ask and It Is Given』（2004）とされる。日本語版の訳語は、ことはちゃんは確認できていない。
- この図は、心理学で検証された尺度ではない。スライドには「ある考え方の紹介です（科学的に検証された尺度ではありません）」を必ず入れる。
- 和訳はことはちゃんが付けた。本の訳語と違えば、本を優先する。

## 美智代さんの本との照合ポイント
1. 本は、1〜7に「愛・感謝・喜び・情熱・楽観・希望…」、8〜22に「イライラ・疑い・心配・怒り・自信喪失・無力感…」と書いている。→ **大筋は一致**。
2. 本は「自己否定感（自分はダメだ）がもっともネガティブ度が高い」と説明している。この表では、自己否定に近いのは21（自分には価値がない感じ）、22は恐れ・絶望・無力感。→ **この点は本と少しずれる**。スライドでは、本の言い方に合わせるか、「自分には価値がない感じ」を重い側として強調する形にする。
3. 日本語版の訳語・番号が違えば、本を優先して直す。

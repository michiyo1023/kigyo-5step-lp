## 2. 作るもの
- 全7回、各回1ファイルのスライド。形式：**PowerPoint（.pptx）、16:9**
- 保存先：`slides/brain-course/` に、`第1回.pptx` 〜 `第7回.pptx`
- 06の表の **No（S1-01など）と同じ枚数・同じ順番** で作る。勝手に増減しない。
- 各スライドの右下に、No（例：S2-05）を小さく入れる。
- 各スライドのスピーカーノートに、No だけ書く（ナレーション本文は、あとで別の担当が入れます）。

## 3. 守ること
1. 表の「画面に出す文字」は、一字一句そのまま使う。言い換えない。
2. 1スライド1メッセージ。文字は大きく、余白を多く。本文は原則40文字以内。
3. 禁止語：魂／波動／神様／奇跡／引き寄せ／好転反応／言霊／「脳大成理論」／「突然ですが」。
4. 書籍のイラスト・図・文章は使わない。図は、すべてオリジナルで作る。
5. 色・フォント：落ち着いた配色（濃い紺・やわらかい金・生成り）。日本語フォントは、読みやすいゴシック体。
6. 「（美智代さん記入）」「（美智代さんが調整）」「（美智代さんの言葉）」と書かれた箇所は、**空欄の枠**として残し、中身を作らない。
7. 第2回の感情の段階（22段階）の図は、06の指示どおり、**確認できた言葉だけ**を置く。番号や名称を自分で補わない。「ある考え方の紹介です（科学的に検証された尺度ではありません）」の注記を必ず入れる。
8. 研究の話は、「〜という研究があります」と小さく添える。著者名や年は、スライドに書かない。
9. ワークのスライドには、タイマー用の分数を大きく入れる。

## 4. 作業の進め方
1. まず **第1回だけ** 作る。
2. 作ったら、各スライドを画像に書き出して、文字のはみ出し・重なり・読みにくさを自分で確認し、直す。
3. 第1回の確認が済んでから、第2回〜第7回を作る。
4. 最後に、全ファイルを `slides/brain-course/` にコミットして、同じブランチへpushする。（プルリクエストは作らない）

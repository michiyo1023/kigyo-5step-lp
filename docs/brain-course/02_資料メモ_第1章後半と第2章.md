## 1. 資料の要点
| 箇所 | 要点 |
|---|---|
| Q4の続き：+100と−1 | 積み重ねを「点数」で説明。+100の人が1回ネガティブを言っても+99。ゼロに戻らない。悲観して「もう無理」とやめてしまうのが一番もったいない。気を取り直して続ければよい |
| Q5：ながら唱えはOK？ | OK。義務感でこなすより、楽しみながらの方が続く。料理中・信号待ちなど。ただし始めたばかりで意識が曖昧になるなら、最初の3ヶ月は避ける。「何分で何回言えるか」を計るとよい |
| Q6：他にも併せてやるとよいことは？ | 記録する（ダイエットで体重を計るのと同じ）。部屋を整える、自然に触れるなども、無理に新しく始めなくてよい |
| 第1章のまとめ | 目覚めた時と寝る前が「ゴールデンタイム」。違和感があれば言葉を変える。「口にして“よい音”と感じるか」を判定のカギにする。基礎体力の目安は1日1000回×3ヶ月 |
| Work④：約束リスト | 自分との約束を3〜5個、朝か前日の夜に書く。できたらチェック。内容はごく簡単でよい（朝ごはんを食べる、洗濯する等）。慣れても無理に増やさない。続けると「自分が好きになってきた」と感じる人が多い |
| Work⑤：ありがとう10個チャレンジ | 1日の終わりに、感謝できることを10個書く。ささいなことでよい（コーヒーがおいしい、無事に職場へ行けた等）。10個に満たなければ無理せず、思いつく限りでよい。「今日」に限らなくてもよい。書くと「こんなにあるのだな」と実感でき、探す感度が高まる |
| Work⑥：悪口を「キャンセル」 | 悪口・グチを言ってしまったら、すぐあとに（できれば1時間以内に）「いまのナシ」と言う。自分を責めない。明るく言い直す。その場を離れてから「ありがとう」を多めに言うのも可。人のグチを聞く場にいなければならないときも使える |
| 言葉の転換 | 「疲れた」→「充実していた」、「つまんない」→「自分で楽しくしていこう」、「やる気が出ない」→「今日は簡単な作業の日にしよう」 |
| コーヒーブレイク2：休む日 | できない日があってもよい。休むと決めた日は「休む日」としてOK。ただし翌日にリカバリーできるか、を問う |

## 2. 脳科学の言葉への翻訳（案）
| 資料の内容 | 脳科学・心理学の言い方 | 使い方 | 確信度 |
|---|---|---|---|
| +100と−1の点数のたとえ | 一度の失敗で全体は崩れない。「やめる」と「戻る」は違う | 「完璧主義が習慣を止める」説明。点数図は講座で使いやすい | 高 |
| 失敗後に「もう無理」と全部やめる | 「どうにでもなれ効果」（1回崩れると全部投げ出す心理）。心理学で知られる現象 | 名前を付けると初心者に刺さる。※正式名称・出典は確認してから使う | 中 |
| 約束リストを書く | 実行意図（いつ・何をするかを決める）、可視化、チェックの達成感 | 「書く→できたら✓」が行動を後押し。小さな約束ほど成功体験になる | 高 |
| 約束を守ると自分が好きになる | 自己効力感（「私はできる」という感覚）が育つ | 起業女性の「自己信頼」のテーマに直結。第2〜3回の核になる | 高 |
| ありがとう10個を書く | 感謝を探す習慣＝注意の向け先を変える練習。感謝日記の研究は多数あるが、効果の大きさには幅がある | 「探す感度が上がる」は選択的注意で説明できる。効果の断言はしない | 中 |
| 悪口をキャンセル→言い直し | リフレーミング（言い換え）、感情のラベリング、自己批判を止める | 「いまのナシ」は覚えやすい。「自分を責めない」は自己への思いやり（セルフ・コンパッション）で裏づけやすい | 中〜高 |
| 「疲れた→充実していた」の言い換え | 認知の再評価（同じ出来事の意味づけを変える） | ただし「無理にポジティブ」にしない。違和感が出る言い換えは逆効果になりうる | 中 |
| 休む日があってもよい | 回復も習慣の一部。休む日を「決めておく」と罪悪感が減る | 続けるための設計として強い。「サボる」と「休む」の区別を教える | 中 |
| 記録して可視化（体重の例） | セルフモニタリング（自分の行動を記録すると変わりやすい） | 習慣マス表・記録のワークに使える | 高 |
| 「口にして“よい音”と感じるか」 | 自分の感覚（違和感）に気づく練習 | O-リングの代わり。「言って、体と気分がどう動くか」を観察する | 中 |

## 3. 使わない・変える判断
1. **「言霊の効果をみたいときはO-リングテスト」は使わない**（前回と同じ判断）。体感の観察ワークに置き換え。
2. **「最強の言霊」「たくさんの人の感謝のパワーが凝縮」「室町時代以前から」は使わない。** 科学的な根拠がなく、検証もできない。「古くから使われてきた感謝の言葉」程度に留めるか、省く。
3. **「+100点」「−1点」の数字は、たとえとして使う。** 実際に点数で計算できるものではないと、一言添える。
4. **約束は「簡単で小さく」が脳科学とも合う。** そのまま採用できる。ただし資料の「3ヶ月で変わる」は目安扱い。
5. **「うつ病の回復」「母親の話」は使わない。** 約束・保証に見えるため。

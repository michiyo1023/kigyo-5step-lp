## 先に決めること：ドメインに何を背負わせるか

ドメインは一度決めたら何年も使います。
**商品名（口コミ集客講座）を入れると、商品を変えたときに古くなります。**
ホームページは「本体」なので、**看板（マインドチューニング）か、ご本人の名前**のどちらかにするのが基本です。

## A．看板（ブランド）で取る【本命】

| 案 | ひとこと |
|---|---|
| **mind-tuning.jp** | いちばん素直。看板とそのまま一致 |
| mindtuning.jp | ハイフンなし。見た目はすっきり、口で伝えるときは区切りが伝わりにくい |
| mindtuning-master.jp | 看板のフルネーム。長いけど、言い間違いは起きにくい |
| tuning-mind.jp | Aが取れなかったときの代わり |
| mindtuning-lab.jp | 「研究所」っぽさで、脳科学の専門性を出せる |

**おすすめ：mind-tuning.jp（確信度：中）**
理由：短い／看板と一致／商品が変わっても使える／「マインドチューニング、ハイフン入りで」と口で伝えやすい。
注意：「mindtuning」は英語圏で使われやすい言葉なので、.com は取られている可能性が高い（推測・確信度：中）。.jp のほうが残っている可能性あり。

## B．名前で取る【一生ものにするなら】

- 〇〇michiyo.jp ／ michiyo-〇〇.jp （〇〇＝名字のローマ字）

肩書きや看板が将来変わっても使えるのが強み。
ただし「みっちゃん」をローマ字にした mitchan 系は、NG（アルファベットのニックネーム表記）に当たるので外しています。

## 末尾（.jp / .com）の選び方

- **.jp**：日本の住所があれば取れる。日本の人に「ちゃんとしている」印象。**本命**
- **.com**：世界共通。空いていればセットで押さえるのもあり
- **.co.jp**：法人登記が必要。今が個人事業なら対象外

## 検討メモ：「michiyo.s」案（2026-10-07）

**そのままでは取れない。** ドメインの最後の「.s」の部分に当たる末尾が存在しないため。
形を変えれば使える：

| 案 | 読み上げ方 | ひとこと |
|---|---|---|
| **michiyo-s.jp** | みちよ、ハイフン、エス、ドット、ジェーピー | 「michiyo.s」に一番近い。SNSのIDとそろえるならこれ |
| michiyos.jp | みちよズ | 「みちよの（場所）」と読める。ただ複数形にも見える |
| michiyo-s.com | | .jp が取れなかったときの代わり |

**良いところ**
- 名前なので、看板や商品が変わっても一生使える
- SNSのIDが michiyo.s なら、ID・ドメインがそろって覚えてもらいやすい

**気になるところ**
- 「s」が何の頭文字か、初めて見た人にはわからない
- ドメインだけでは、何をしている人かは伝わらない（名前で選ばれる段階なら問題なし）

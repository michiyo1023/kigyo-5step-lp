## 先に決めること：ドメインに何を背負わせるか

ドメインは一度決めたら何年も使います。
**商品名（口コミ集客講座）を入れると、商品を変えたときに古くなります。**
ホームページは「本体」なので、**看板（マインドチューニング）か、ご本人の名前**のどちらかにするのが基本です。

## 末尾（.jp / .com）の選び方

- **.jp**：日本の住所があれば取れる。日本の人に「ちゃんとしている」印象。**本命**
- **.com**：世界共通。空いていればセットで押さえるのもあり
- **.co.jp**：法人登記が必要。今が個人事業なら対象外

## 検討メモ：「michiyo.s」案（2026-10-07）

**そのままでは取れない。** ドメインの最後の「.s」の部分に当たる末尾が存在しないため。

| 案 | 読み上げ方 | ひとこと |
|---|---|---|
| **michiyo-s.jp** | みちよ、ハイフン、エス、ドット、ジェーピー | 「michiyo.s」に一番近い。SNSのIDとそろえるならこれ |

| michiyo-s.com | | .jp が取れなかったときの代わり |

**良いところ**
- 名前なので、看板や商品が変わっても一生使える
- SNSのIDが michiyo.s なら、ID・ドメインがそろって覚えてもらいやすい

**気になるところ**
- 「s」が何の頭文字か、初めて見た人にはわからない

口コミ集客では、紹介は**名前**で回る。
「志田美智代さんっていう人がいてね」と聞いた人は、名前で検索する。
そのとき、名前そのままのドメインが出てくるのが一番迷わない。
特典にも「志田の他講座」とあり、すでに名前で商品を束ねている。

## 検討メモ：.jp と .com どっちがいい？（2026-10-08）

**結論：.jp がいい。** お客様が日本の40〜50代女性なら、.com を選ぶ理由は特にない。

| 比べるところ | .jp | .com |
|---|---|---|
| 取れる人 | 日本に住所がある人だけ（確信度：高） | 世界中の誰でも |
| 見た人の印象 | 日本の人・ちゃんとした人 | ふつう。印象の差は小さい |
| 検索での強さ | 日本向けなら差はほぼない（確信度：中） | 同じ |
| 年間の費用 | 高め。更新は年3,000〜4,000円前後（確信度：中） | 安め。年1,500〜2,000円前後（確信度：中） |
| 弱いところ | 打つときに「.com」とクセで打ち間違えられることがある | 誰でも取れるので、いい名前は先に取られやすい |

**取るときの注意**
- 初年度だけ安い「キャンペーン価格」が多い。**2年目からの更新費用**を必ず見る
- 自動更新をオンにする（うっかり期限切れでドメインを失うのが一番こわい）

**.com も取る？**
- 必須ではない。予算に余裕があれば、名前ドメインだけ .com も押さえておくと、打ち間違い・なりすまし防止になる

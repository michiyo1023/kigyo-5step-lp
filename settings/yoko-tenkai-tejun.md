# いつもの横投稿の手順（note → Pinterest → Instagram → Threads）

元の資料：ビジネス実践講座 第8回「ブログ→Pinterest→Instagram 横展開のやり方 プロンプト集」（株式会社オフィス凛）
https://docs.google.com/document/d/1FDHdNnw5BuDU1Iq-MPUvcxY49TwryFoEHCOyszv2Qzk/edit
※資料のブログ（WordPress）を、美智代さんは note に置き換えて使う。2026/10/20 美智代さんより「この手順を覚えておいて」。

## 基本の考え方
- 1本書いて、3か所に出す。毎日ネタを探さない。月1本でいい。
- 「あとで書く」は書かない。その場で公開まで持っていく。完璧でなくていい。
- 場所ごとに役割が違う。ここを間違えると、横展開しても人が来ない。

| 場所 | 目的 | 書き方 |
|---|---|---|
| note（ブログ） | 検索から来てもらう | 答えを先に書く |
| Pinterest | クリックしてもらう | 全部書かない |
| Instagram | 保存してもらう | 全部書く。その場で読み終わる |
| Threads | 記事を知らせる | URL＋ひとこと |

## 準備（毎回、先に確認する）
- ペルソナ／USP／スタイルガイド／今日書くテーマ（検索語リストから選んだもの）
- 特にスタイルガイドの有無で文章がまったく変わる。手元にないときは美智代さんに貼ってもらう。

## 1. note を書く
1. **構成を先に出す**（いきなり本文を書かない）
   - 見出し（H2・H3）だけ。検索した人が知りたい順番に並べ、その順番の理由も添える。
   - 確認：お客様が本当に知りたい順か／誰にでも当てはまる話になっていないか／美智代さんの言いたいことが入っているか。
2. **本文**
   - 2000字程度／答えを先に（結論ファースト）／1段落は3行まで／専門用語は使わない
   - 最後に、次の行動（申込・メルマガなど）への流れを作る。
3. **精査**（声に出して読む）
   - 普段使わない言葉が入っていないか／嘘や盛った実績が入っていないか／読んだ人が次にどうしたくなるか
4. **タイトルなど**
   - タイトル5案：32文字以内、検索されそうな言葉を前に、選んだ理由つき。理由を言えない案は採用しない。
   - ディスクリプション（120字程度）・パーマリンク（英数字とハイフン）は WordPress 用。note では使わない。
5. **アイキャッチ画像**：記事の顔。あとで Pinterest にも使う。
   - 資料では 1200×900（横長）。※note の見出し画像は 1280×670 が推奨（確信度：中）。どちらに合わせるか美智代さんに確認する。
   - AIが作った日本語の文字は崩れることがあるので、目で確認。崩れたら作り直すか、文字だけCanvaで載せる。
6. 公開 → URLをもらう。

## 2. Pinterest
- アイキャッチを **縦長 1000×1500** にリサイズして使う（作り直さない）。タイトルの文字が切れないように。
  - Canvaのリサイズ機能は有料。無料なら 1000×1500 で新規作成し、要素をコピーして貼る。
- ピンのタイトル5案（30文字前後）＋説明文1案（150〜200字）。
- **ハッシュタグは入れない**（説明文の言葉そのもので検索される）。検索する人が打ちそうな言葉を入れる。
- リンク先は note の記事。

## 3. Instagram（カルーセル）
- 外へのリンクが貼れない → その場で読み終わる形にして「保存」してもらう。Pinterestとは逆。
- **1080×1350（縦）で10枚**：1枚目＝表紙／2〜9枚目＝中身（見出し＋箇条書き3〜4行）／10枚目＝ご案内
- 表紙は、テンプレートに入る文字数（◯文字×3行）を**先に数える**。数えずに作るとはみ出す。→ 美智代さんのテンプレートの文字数を確認する。
- **画像の文字は短く、細かい説明は入れない。詳しい話・体験談・理由は、キャプションで書く**（2026/10/20 美智代さんのルール）。
  - 1枚あたり：見出し（大）＋短い一言〜2行まで。本文を3〜4行並べない。
  - 画像から外した話は、キャプションに入れ直す。
- デザインは、美智代さんの好きな表紙（淡い水彩・金・大きな明朝体・強調は1語だけ色をつける）を基準にし、**2枚目以降は1枚ごとに色とイラストを内容に合わせて変える**。人物・吹き出しは入れない。画像はCodexで作る（下の「Codexで画像を作るとき」）。
- 記事の順番どおりでなくていい。最初の3枚で「続きが読みたい」と思わせる。
- キャプション：
  - スタイルガイド（Instagram用）に合わせる
  - **書き出しは断言。問いかけから入らない**
  - 400字程度
  - 最後はプロフィールのリンクへ誘導
  - **ハッシュタグは入れない**
- noteの文章をそのまま貼らない。読む場所が違うので書き方を変える。
- Canvaで1枚目だけ作り込み、2枚目以降は複製して文字を差し替える。

## 4. Threads
- 記事のURL＋ひとこと。**300字程度**、冒頭にいちばん言いたい一行。
- （資料ではこのあとXの140字版も作る。美智代さんの「いつもの」にXは入っていない。）

## 困ったとき
- しっくりこない → 「普段使わない言葉を指摘して、書き直して」
- 長すぎる → 「半分にして。お客様に大事な情報は残して、何を削ったかも教えて」
- テーマが思いつかない → 検索語リストから「最初に書くべきもの3つと理由」を出してもらう

## Codexで画像を作るとき
- クラウドのセッションでは、Codex（`@openai/codex`）をその都度入れ、`codex login --device-auth` で美智代さんのChatGPTアカウントにログインする（コードを入れてもらう）。鍵は使わない。
- 頼み方：頼む文をファイルにして標準入力で渡す。お手本の画像は `--image` で添付する。保存先・サイズ（1080×1350など）・「ほかのファイルは変えない」を必ず書く。
- 日本語の文字は「一字一句そのまま、足さない・変えない」と指定し、できた画像は必ず目で確かめる（難しい漢字は拡大して確認）。
- 直すときは、画像を添付して「ここだけ変更、ほかは変えない」と頼む。

使い方：下の「お願い文」を、パソコンで動くことはちゃん（Claude in Chrome をつないだ会話）に、まるごと貼って送る。

## お願い文（ここから下をコピー）

リザストのステップメール「寄り添いタイプ」に、メールを9通入れてください。

【貼る中身】
- GitHub の michiyo1023/kigyo-5step-lp の、ブランチ claude/ecstatic-wozniak-yakghk にあります。
- フォルダ：notes/stepmail/yorisoi/
- 1通ごとに、件名（N-kenmei.txt）、本文の文字版（N-honbun.txt）、本文のHTML版（N-honbun-html.html）があります。Nは1〜9。
- 送る日は、同じフォルダの README.md の表のとおりです（1通目＝登録の翌日、2通目＝2日後 … 7通目＝7日後、8通目＝締切の前日、9通目＝締切の当日）。

【やり方】
1. Chrome で、すでにログインしているリザストの管理画面を開く。
2. ステップメール一覧から「寄り添いタイプ」（371184番）を開く。
3. 1通目を追加する。件名と本文を貼り、送る日を設定して保存する。
   - 本文の欄に「ソース」や「HTML」のボタンがあれば、HTML版を貼る。なければ文字版を貼る。
4. 1通目を保存したら、いったん止まって、私に画面を見せて確認をとる。
5. 私が「OK」と言ったら、2通目から9通目まで同じように入れる。
6. 最後に、9通の件名と送る日の一覧を見せる。

【守ってほしいこと】
- 配信・予約配信・テスト送信・削除はしない。保存（下書きの状態）まで。
- 「寄り添いタイプ」以外のステップメールやメルマガは、さわらない。
- 8通目・9通目の送る日は、締切日が決まっていなければ、仮の日数で入れて、あとで直すと教えてください。
- わからない画面が出たら、自分で判断せずに、スクショを見せて聞いてください。

## 美智代さんの準備（最初の1回だけ）
1. Chrome に「Claude in Chrome」（拡張機能）を入れて、Claude と同じアカウントでログインする
2. 同じ Chrome で、リザストの管理画面にログインしておく

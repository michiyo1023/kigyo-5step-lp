# Chromeのことはちゃんへのお願い文（伴走タイプ 9通）

使い方：下の枠の中をコピーして、Chromeの右側のClaudeの欄に貼って送る。

## お願い文（ここから下をコピー）

リザストのステップメール「伴走タイプ」に、メールを9通入れてください。

【貼る中身】
次のページを新しいタブで開くと、件名と本文が読めます。Nのところを1〜9に変えてください。
- 件名：https://raw.githubusercontent.com/michiyo1023/kigyo-5step-lp/claude/charming-sagan-jlhilv/notes/stepmail/bansou/N-kenmei.txt
- 本文（文字）：https://raw.githubusercontent.com/michiyo1023/kigyo-5step-lp/claude/charming-sagan-jlhilv/notes/stepmail/bansou/N-honbun.txt
- 本文（HTML）：https://raw.githubusercontent.com/michiyo1023/kigyo-5step-lp/claude/charming-sagan-jlhilv/notes/stepmail/bansou/N-honbun-html.html

【送る日】
1通目＝登録の翌日、2通目＝2日後、3通目＝3日後、4通目＝4日後、5通目＝5日後、6通目＝6日後、7通目＝7日後、8通目＝締切の前日、9通目＝締切の当日

【やり方】
1. 今開いているリザストの管理画面で、ステップメール一覧から「伴走タイプ」を開く。見つからないときは、新しく作らずに止まって聞く。
2. 1通目を追加する。件名と本文を貼り、送る日を設定して保存する。
   - 本文の欄に「ソース」や「HTML」のボタンがあれば、HTML版を貼る。なければ文字版を貼る。
3. 1通目を保存したら、いったん止まって、私に確認をとる。
4. 私が「OK」と言ったら、2通目から9通目まで同じように入れる。
5. 最後に、9通の件名と送る日の一覧を見せる。

【守ってほしいこと】
- 配信・予約配信・テスト送信・削除はしない。保存（下書きの状態）まで。
- 「伴走タイプ」以外のステップメールやメルマガは、さわらない。
- 8通目・9通目の送る日は、締切日が決まっていなければ、仮の日数で入れて、あとで直すと教えてください。
- わからない画面が出たら、自分で判断せずに、止まって聞いてください。

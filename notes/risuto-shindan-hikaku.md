# リザスト無料診断 3種類の違い（メルマガリスト集め用）

調べた日：2026-10-16
※公式ヘルプとブログ記事を調べてまとめています。ファストタイプは新しい機能で、情報がまだ少ないです。

## ひとことで

| | ファストアンサー | ファストスコア | ファストタイプ |
|---|---|---|---|
| 正式な呼び名 | 簡易診断 | 検定 | タイプ別診断 |
| しくみ | 選んだ答え → それに合う文章が届く | 答えごとの点数を足す → 合計点で結果が変わる | 答えから「あなたは◯◯タイプ」を判定 |
| 向いている使い方 | 1問だけの、気軽な「◯◯チェック」 | 「あなたの集客力は何点？」のような点数・レベル診断 | 「4タイプのどれ？」のような性格・タイプ診断 |
| 結果によってメルマガを分けられるか | 確認できず | できる（例：30点以上はA、70点以上はB） | 確認できず |
| 料金プラン | 無料プランでも使える | 無料プランでも使える | **有料プランだけ**（無料プランでは使えない） |
| 情報の確かさ | 高 | 高 | 中（2026年8月に追加された新機能。詳しい説明が少ない） |

共通点：どれも「メルマガ読者集め」メニューの中にあります。診断に答えた人は、あらかじめ決めておいたメルマガ・ステップメールに**自動で登録**されます。だから、リストを増やす入口として使えます。

## 1. ファストアンサー（簡易診断）
- 選択肢を選ぶと、その答えに合わせた文章がメールで届きます。
- 点数の計算はしません。
- 作るのがいちばん簡単です。最初の1本を「7割の出来」で出すのに向いています。
- 弱いところ：答えた人が「当たってる！」と感じるほどの深さは出しにくいです。

## 2. ファストスコア（検定）
- 答えごとに点数をつけます（マイナス点も使えます）。合計点で結果のメールを変えます。
- 結果によって、送るステップメールやメルマガを分けられます。
- これまでの「タイプ診断」は、「0〜30点＝Aタイプ」のように点数の範囲をタイプ名に置きかえて作っていました。ただ、ものさしが1本（点数の高い・低い）しかありません。なので、本当のタイプ分けというより「レベル分け」になりがちです。
- 弱いところ：答えた人が何を選んだかは見えにくく、合計点しか分かりません。

## 3. ファストタイプ（タイプ別診断）
- 2026年8月ごろに追加された新しい機能です。
- 質問・タイプ・点数を設定すると、答えからタイプを判定して、結果を返してくれます。
- 確信度：中。「どのタイプに何点入るか」を積み上げて、いちばん点数の多いタイプを出すしくみ、と推測しています。管理画面で必ず確かめてください。
- 有料プランだけの機能です。

## 美智代さんへのおすすめ

**本命はファストタイプ。使えないプランなら、ファストスコアを「レベル診断」として使う。**

理由：
- ターゲットは「すでに学び、動いているのに結果につながらない女性」です。「あなたは初心者です」と点数で言われるより、「あなたは◯◯で止まっているタイプ」と言われるほうが、「そう、これが言いたかった」が起きます。
- 「人の詰まりを構造でほどく設計者」という強みも、そのまま診断の形にできます（タイプ＝詰まっている場所）。
- 結果のメールのあとに、タイプ別のステップメールへ分けられると、体験講座 → 本講座（脳科学で選ばれる口コミ集客実践講座）への流れが自然につながります。

注意（導線の詰まりポイント）：
- ファストタイプで「タイプごとにメルマガを分けられるか」は、まだ確認できていません。分けられない場合は、1本のステップメールの中でタイプ全部に呼びかける書き方にする必要があります。
- ファストスコアでいくなら、点数が低いと「あなたはダメ」と受け取られます。結果の文章は「伸びしろ」と言いかえる設計が必要です。

## ファストタイプの作り方（2026-10-16 時点）

公式の手順書は、ネットでは見つかりませんでした。
- 確信度：高＝ブログで確認できたこと
- 確信度：低＝ファストスコアの作り方からの推測

### 画面での手順（2026-10-16 美智代さんのスクリーンショットで確認）

**新規作成の画面**
- ファストタイプの名称（必須）
- 回答者をこの配信グループ（読者として）に追加する：**1つだけ選べる**
  - 初めから入っている選択は「クチコミで人気教室運営・セラピストになれるメール講座」。意図したものか確認すること
- LINEでの登録を可能にする（使うには、先に公式LINE連携の設定が必要）
- LPのテーマ選び（124種類）。選ぶと、タイプ診断のページの形を自動で作ってくれる

**作ったあとの編集メニュー**
| メニュー | やること |
|---|---|
| 概要/設定 | 名称・配信グループなど |
| メインビジュアル | LPの一番上の画像 |
| 告知文の編集 | LPの文章（診断を受けたくなる文章） |
| 入力項目の編集 | 名前・メールなど、答える人に入れてもらう項目 |
| 質問と回答の設定 | 質問・選択肢・点数（※画面は未確認） |
| タイプの設定 | タイプは**2〜12個**。「タイプ名」と「見出しメッセージ」を入れる。初めは見本の5タイプ（犬・猫・うさぎ・サイ・ライオン）が入っている |
| 回答メール文章の編集 | 結果を知らせるメールの文章 |
| 回答後オススメ | 結果のあとに案内するもの（※画面は未確認。タイプごとに変えられるなら、ここが体験講座への入口になる） |
| プレビュー | 自分で試す |
| 回答一覧・回答集計・アクセス解析 | 結果の確認 |

**おすすめの作る順番**
1. 新規作成（名称・配信グループ・LPテーマ）
2. タイプの設定（見本の動物タイプを、自分のタイプに書きかえる。不要なタイプは消す）
3. 質問と回答の設定
4. 回答メール文章 → 回答後オススメ
5. 告知文 → メインビジュアル → 入力項目
6. プレビューで、全部のタイプが出るか自分で試す
7. 公開

**導線の注意**
- 配信グループは1つだけ。だから、どのタイプの人も同じステップメールに入る（確信度：中）。ステップメールは「全タイプに通じる内容」で書くこと。
- タイプ別に分けて案内できる場所は、「回答メール」と「回答後オススメ」の2つ（確信度：中）。

### 先に紙の上で決めること（ここが診断の質を決める）
1. ゴール：診断のあと、どのステップメール → 体験講座へつなぐか
2. タイプ：3〜4個。「詰まっている場所」で分ける
3. 質問：8〜10問。どの選択肢がどのタイプに何点入るかを表にしておく
4. 結果の文章：タイプごとに「代弁 → 原因 → 次の一歩」の順で書く

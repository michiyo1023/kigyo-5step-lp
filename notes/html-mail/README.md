# タイプ別 HTMLメール（貼り付け用）

リザストのタイプ編集画面の「HTMLメール」欄に、管理画面から貼る。
文字メール欄は、窓口（API）から記号なしの文を入れてある。

| ファイル | 貼るタイプ |
|---|---|
| 1-yorisoi.html | 寄り添いタイプ |
| 2-michishirube.html | 道しるべタイプ |
| 3-bansou.html | 伴走タイプ |
| 4-hirameki.html | ひらめきタイプ |
| 5-hashiwatashi.html | 橋わたしタイプ |

貼り方：HTMLメール欄のエディタで「ソース」（または「HTML」）ボタンを押してから、ファイルの中身を全部貼る。

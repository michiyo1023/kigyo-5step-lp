# トークリール台本スキル（通常用）

元資料（Googleドキュメント。ルールが食い違ったら、こちらを正とする）
- マニュアル：https://docs.google.com/document/d/1CPid-3vZYocU99LSuVZJy19cAhX8AyshU1lers5HmsY/edit
- テンプレート：https://docs.google.com/document/d/14SRdwdPTCifv1cJW66OQAF8jjKTi4GU6q23W8HGsDt4/edit

注意：マニュアルの秒数・文字数・個数は実測ではなく「新規の推奨値」（2026-10-25作成）。通常用の実際の台本が見つかったら、その実測値に合わせて直す。

## このスキルの使い方（入力は「ある一言」）
美智代さんが渡す一言から、美智代さんの大切にしていることを言い当てる台本にする。

1. 一言を受け取る（例：「頑張っているのに、なぜか届かない」）
2. その一言の奥にある「美智代さんが大切にしていること」を1つだけ選ぶ（下の候補から。1リール＝1メッセージ）
3. 選んだ大切なことを案として見せ、合っているか聞く。違えば選び直す
4. 実体験メモを聞く。なければ「なし」。**体験は作らない**
5. 台本を3パターン作る（フックの型を変える）
6. チェックリスト8項目に自分で答え、直してから渡す
7. ファイルに保存する。チャットに流すだけにしない

### 美智代さんの「大切なこと」候補（プロフィールより）
- 人の詰まりは、努力不足ではなく構造でほどける
- 学んだことも、資格も、キャリアも、無駄ではない。仕組みになれば自然と売上に変わる
- 心の自立と、経済的な自立
- 自分に投資する覚悟を決めた人が、自分の力で進める
- 全員に優しくしない。本気で動く人を選ぶ
- 「この人生でよかった」と思える人を増やしたい
- 凛とした導き：今のままでは変わらない。でも、あなたなら変われる

## A 形のルール（○×で判定）
- 長さ：45〜60秒、270〜360字。×400字超、×200字未満
- フック：最初の3秒・20字以内。型は次の5つから1つ
  ①当たり前に異議 ②常識をひっくり返す ③意味が一瞬わからない言い切り ④問いかけ ⑤警告型（煽りすぎない）
  見た人の心の声を先に言葉にするのも○
  ×「こんにちは」「みなさん」「突然ですが」で始める ×「〇〇をしています」の自己紹介フック
- 結び：共感ベースの締め＋ありがとうの一言。
  ×プレゼント・LINE登録などの案内を台本に入れる（案内はキャプションに書く）
- 「あなた」：0〜2回。使うなら③の後だけ。×冒頭で呼びかける
- 文：1文40字以内。話し言葉（〜なんです／〜だったの／〜よね）。×書き言葉
- 絵文字は台本に入れない。感嘆符は0〜1個（フックの10字以内の言葉だけ）
- 字幕：1画面15字以内、2行まで。話す言葉と同じにする
- 使わない言葉：「〜すべき」「〜しなさい」「〜しましょう」／「知らないと損」「今すぐ」「手遅れ」／「まずは」「〇〇するだけでOK」／アルファベットのニックネーム

## B 中身のルール
話の運び（この順。入れ替えない）

| パーツ | 目安 | 内容 |
|---|---|---|
| ① フック | 3秒・20字 | 指を止めさせる一言 |
| ② 代弁 | 10秒・60字 | 言葉にできなかったモヤモヤを先に言葉にする |
| ③ 実体験（弱さ） | 15秒・90字 | 失敗・つまずき・後悔。1つの場面に絞る |
| ④ 気づきと一つの学び | 18秒・110字 | 「でも」でつなぎ、気づきを1つだけ |
| ⑤ 共感フォローCTA | 8秒・50字 | 共感ベースの締め |

- ×④を②より前に置く ×③を飛ばす ×学びを2つ以上詰める
- 翻訳して話す：抽象語で一気に説明しない。例 ×「不安でした」→ ○「投稿したあと、スマホを何度も開いては閉じていました」
- 情景が浮かぶ言葉（時間・場所・しぐさ）を1台本に1つ以上入れる
- 弱さの言葉（苦手／後悔／甘かった／凹んだ）を1回以上。直後の1文以内に「でも／それでも／だからね」で前へ進める
- 実体験は勝手に作らない。案を出す場合は【要確認：美智代さんの体験に差し替え】をつける
- 凛とした温度：やさしいだけで終わらせない。例「今のやり方のままでは変わりません。でも、順番を変えたら動きます」
- ×依存的な人に向けた言い方 ×「ゼロからの初心者さん向け」だけに見える言い方
- 数字・出来事は言い切る。自分の解釈には「と思う／と感じる／んです」をつける
- ×根拠のない断定（100％）、×煽りすぎ、×出典のはっきりしない数字・研究名
- 脳科学・心理学の言葉は、中学生に伝わる言い換えを同じ文に添える

## C この人らしさ（観察できる形）
1. ①②で、読者の本音を代弁している
2. 実体験のあと1文以内に、逆接（でも／それでも）で前向きにつなげている
3. 最後まで聞いた人が「私もやってみようかな」ではなく「私のことだ」と感じる終わり方

## 用語（このリポジトリのCLAUDE.mdより）
- 「脳大成理論」は使わない。言い換えは「脳科学」「認定を受けて教えている脳科学の理論」
- 「チューニング（調律）」はブランドの言葉、「セルフクリアリング」は潜在意識の手法名。別レイヤーで両立する

## 出力の形
1. 選んだ「大切なこと」と、一言との結びつき（2行）
2. 台本3パターン（フックの型を変える。各パートの文字数つき）
3. 字幕案（15字以内）
4. キャプション案（300字程度。台本と別の角度。CTAは1つ：もっと知りたい人へ／プレゼント／コメント／シェア）
5. チェックリスト8項目の結果（はい／いいえ）

## 台本チェックリスト（はい／いいえ）
1. 声に出して45〜60秒（270〜360字）に収まる
2. 最初の20字がフックの型で、「こんにちは」「突然ですが」「〇〇をしています」で始まらない
3. フック→代弁→実体験→気づき→共感CTAの順
4. 実体験が1場面あり、弱さの言葉が1回以上。作った体験には【要確認】
5. 弱さの直後1文以内に「でも／それでも／だからね」
6. 学びが1つだけ
7. 命令形・煽り語・決まり文句・プレゼントや登録の案内がない
8. 1文40字以内、書き言葉なし、字幕と話す言葉が同じ

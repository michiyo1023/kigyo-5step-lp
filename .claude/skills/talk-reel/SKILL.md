# トークリール台本スキル（下書き）

※ 構成は一般的なショート動画の型をベースにした仮案。美智代さん独自の型があれば、確認して差し替えること。

## 前提（毎回守る）
- ターゲット：すでに学び動いているのに、集客・収入につながらない40〜50代の起業女性
- 導線：最終的に、バックエンド講座「脳科学で選ばれる口コミ集客実践講座」へつながる設計にする
- 「脳大成理論」という名前は使わない。言い換えは「脳科学」「認定を受けて教えている脳科学の理論」
- 「突然ですが」は使わない。依存的な人に向けた表現も避ける
- 「チューニング」はブランドの言葉、「セルフクリアリング」は潜在意識の手法名。別レイヤーで両立する

## 台本の型（30〜45秒・話し言葉で約200〜300字）
1. **フック（0〜3秒）**：読者の本音を代弁する一言。例「こんなに学んだのに、なぜ申し込みが来ないんだろう」
2. **共感の翻訳（〜10秒）**：モヤモヤを一段ずつ言葉にする。説明ではなく追体験にする
3. **構造の提示（〜25秒）**：原因は努力不足ではなく「仕組み」にある、と脳科学の視点で短く示す
4. **凛とした一言（〜35秒）**：「今のままでは変わらない。でも、あなたなら変われる」の温度で言い切る
5. **次の一歩（〜45秒）**：メルマガ、体験講座、コメントのどれか1つだけに誘導する

## 書き方のルール
- 中学生にも伝わる言葉。短い文。1文1息で言える長さ
- 改行は適度に（多すぎない）
- 情景が浮かぶ表現を1つ入れる
- 完成度より発信量。7割で出す

## 出力形式
1. 台本（話す文章そのまま）
2. 画面テロップ案（3〜5個）
3. キャプション案
4. 撮影メモ（目線・間・声のトーン）

保存先は聞いてから決める。チャットに流すだけにしない。

## 作る前に確認すること
- 元ネタ（メルマガ・投稿・ブレインダンプ）はあるか
- 目的：興味・信頼・交流のどれか（Threadsは 興味5・信頼2・交流3 の配分）
- 誘導先：メルマガ／体験講座／コメント のどれか

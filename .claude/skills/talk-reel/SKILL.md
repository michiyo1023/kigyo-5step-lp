# トークリール台本（60秒・7ブロック）

美智代さん（マインドチューニングマスター／元教員）のトークリール台本を作る。
フレーズ集・型の詳細は、リポジトリの `reel-template-60s.md`、見本は `reel-scripts-3.md` を読む。

## 手順

1. **前提を確認する（足りないものだけ聞く）**
   - テーマ（1文で言える結論）
   - 型：A 意味づけ変換（共感）／B 手放し（保存）／C 凛と導く（覚悟を問う）。指定がなければ、テーマに合う型を選んで理由を一言添える
   - CTA：指定がなければ「2027年の運気と脳傾向診断書（プロフィールから）」
2. **7ブロックで書く**（読み上げ合計 340〜420字、間を入れて約60秒）

   | 秒 | ブロック | 文字数 | 中身 |
   |---|---|---|---|
   | 0–4 | ① フック | 25〜35 | 断言か逆説を1文 |
   | 4–14 | ② 代弁 | 60〜80 | 本音を3行で言語化 |
   | 14–22 | ③ 原因の再定義 | 45〜60 | 努力不足→「〇〇が抜けているだけ」 |
   | 22–32 | ④ 自己開示 | 55〜70 | 事実だけ（元教員・1万人以上と関わってきた） |
   | 32–46 | ⑤ 解決の型 | 90〜110 | 数字の「3つ」で区切る |
   | 46–54 | ⑥ 凛とした締め | 45〜60 | 「今のままでは変わらない。でも、〜なら変わる」 |
   | 54–60 | ⑦ CTA | 40〜55 | 行動は1つだけ |

3. **文字数を数える**。範囲外なら、④→②の行→⑤の補足の順に削る（①③⑥⑦は削らない）。不足なら②か⑤を足す
4. **ファイルに保存する**（チャットに流すだけにしない）。保存先は指定がなければリポジトリ直下 `reel-script-<テーマ短縮>.md`。形式は次のとおり
   - 読み上げ原稿（そのまま読める形）
   - 画面・演出の表（秒／読み／テロップ／演出メモ）
   - 文字数
5. 保存したら、パスと文字数、型の選択理由、確認したい点（あれば）を短く報告する

## 書き方の基準（絶対に外さない）

- 「説明」ではなく「翻訳」。感情を抽象語でまとめず、心の動きを一段ずつ言う
- 読者の本音を先に代弁する
- 凛とした導きの温度。やさしいだけで終わらせず、⑥で必要なことははっきり言う
- 中学生にも伝わる言葉、短い文、適度な改行（多すぎない）
- 1本1メッセージ。脳科学の説明は1本に1回、初出の専門用語はその場で言い換える
- 対象は、すでに学び動いているのに結果につながらない40〜50代の起業女性。依存的な人向けの言い方はしない

## 入れないもの

- 「突然ですが」
- 「脳大成理論」（言い換え：「脳科学」「認定を受けて教えている脳科学の理論」）
- 受講生の実績・売上など、事実が確認できていない数字や話
- 「波動」「お金さん」「宇宙のテスト」など、脳科学の看板とぶれる言葉
- アルファベットのニックネーム表記
- 診断書を「無料」と言うこと（料金が未確定のため）

## 用語

- 「マインドチューニング」：ブランドの言葉。リールで名乗ってよい
- 「セルフクリアリング」：潜在意識を扱う手法名。講座で出す。リールでは使わなくてもよい
- 2つは別レイヤーで両立する
